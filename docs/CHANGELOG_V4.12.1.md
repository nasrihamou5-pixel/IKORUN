# IKORUN 4.12.1 — Le test des 25 semaines n'est jamais perdu
- Test raté ou oublié (empêchement, imprévu) : reporté de quelques jours sur la prochaine séance facile qui ne touche aucun jour dur ; jusqu'à 4 reports.
- Maladie ou blessure : les séances restent allégées le temps de récupérer, puis le test est replacé après la récupération.
- Plus de place avant la course (8 jours minimum) : le test est annulé, les allures restent celles du dernier chrono.
- Le test n'est validé qu'avec le chrono saisi (sans chrono, il reste à faire). Il n'est jamais raccourci ni déplacé par les rééquilibrages du plan.
- Une reconstruction du plan (après une longue coupure) garde la numérotation et ne repose pas un test déjà fait.
