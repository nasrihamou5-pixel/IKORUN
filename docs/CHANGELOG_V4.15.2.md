# IKORUN v4.15.2
- Nouveau programme : juste un nom et des exercices (plus de description, d'objectif, d'icône ni de couleur). Sans nom, il s'appelle « Programme N ».

- Bibliothèque : les tuiles muscle montrent le muscle en couleur sur la silhouette 2D (cadrée sur la région), plus en photo.
- Bibliothèque : matériel, type et niveau dans trois menus sur une seule ligne.
- Animations d'entrée douces (tuiles, cartes d'exercices, programmes, création).
