# V4.21.0 — création de programme et séance en cours plus proches de Lyfta
- Créer un programme : chaque exercice affiche sa miniature, son nombre de séries et un « ⋯ » ; un appui le déplie (note, repos, tableau Série / Précédent / Kg / Reps, « Ajouter une série »). Le « ⋯ » propose remplacer, note épinglée, repos, retirer.
- Les kg/reps prévus pour chaque série sont repris au démarrage de la séance (sauf si tu as un historique pour cet exercice).
- Séance en cours : série cochée = ligne verte, « ⋯ » en couleur, menu d'exercice en feuille du bas (superset, remplacer, note épinglée, repos, retirer), note épinglée dans l'exercice, boutons « Ajouter des exercices » + « Plus » (repos, annuler la séance).
- Correctif Épuré : la carte exercice était transparente, le rouge « Supprimer » se voyait derrière.
