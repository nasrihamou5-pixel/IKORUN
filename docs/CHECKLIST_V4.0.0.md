# IKORUN V4.0.0 — À vérifier sur ton téléphone

À faire sur **iPhone** (Safari, puis l'app installée sur l'écran d'accueil) et sur **Android** (Chrome et Samsung Internet).

Dans chaque section, passe aussi une fois en **arabe** (Profil › Langue) et en **mode clair**.

Recharge l'app une fois après la mise en ligne. La version affichée en bas du Profil doit être **4.0.0**.

## Démarrage et langues
- [ ] L'app s'ouvre sans écran blanc.
- [ ] Profil › Langue › English : tout passe en anglais en moins d'une seconde.
- [ ] Profil › Langue › العربية : l'interface s'affiche de droite à gauche.
- [ ] Ferme et rouvre l'app : la langue choisie est gardée, sans flash en français.
- [ ] Mode avion, puis changement de langue : un message dit « disponible à la prochaine connexion » si la langue n'a jamais été chargée. Sinon, elle s'affiche normalement.

## Bilan et adaptation
- [ ] Sport › une séance passée › bilan « Comme prévu » : l'analyse s'affiche avec le bouton **Partager**.
- [ ] Bilan « Pas fait » › motif › **« J'ai fait autre chose à la place »** : choisir Vélo et 45 min, puis valider. Le choix est gardé.
- [ ] Bilan avec une douleur à 5/10 : les 3 jours suivants passent sans course, avec une explication et un bouton Annuler.
- [ ] Accueil : le check du matin (3 gestes) s'enregistre.

## Image de partage
- [ ] Depuis l'analyse d'un bilan : l'aperçu apparaît tout de suite.
- [ ] Changer de format (story / carré), de modèle, de fond (verre, photo).
- [ ] Photo : glisser pour cadrer, zoomer.
- [ ] **Partager** ouvre la feuille de partage (WhatsApp, Instagram…). Sur ordinateur, l'image est enregistrée.
- [ ] En arabe : le titre et les chiffres restent dans le bon sens.

## Météo
- [ ] Accueil › carte Météo › choisir sa wilaya : la météo réelle s'affiche (température, vent).
- [ ] « Me localiser » : le téléphone demande l'autorisation, puis la météo du lieu s'affiche.
- [ ] Séance du jour : un conseil chaleur s'affiche s'il fait chaud.

## Ramadan
- [ ] Profil › Apparence › Ramadan : les réglages s'ouvrent (il sera actif du 8 février au 8 mars 2027).

## Installation
- [ ] Ouvre ikorun.pages.dev depuis WhatsApp (lien dans une conversation) : un message propose « Ouvrir dans mon navigateur ».
- [ ] iPhone Safari : Profil › Installer l'app montre les étapes avec le bouton Partager.
- [ ] Android Chrome : Profil › Installer l'app ouvre la fenêtre d'installation.

## Courses (après les migrations, voir REGLAGES_MANUELS.md)
- [ ] Sport › icône drapeau (ou Profil › Courses en Algérie) : l'écran s'ouvre. Avant les migrations, il affiche « Calendrier pas encore disponible ».
- [ ] Après avoir ajouté une course test (Profil › Gérer le calendrier › Ajouter) :
  - [ ] elle apparaît dans la liste et dans le calendrier ;
  - [ ] la fiche affiche la carte quand on touche « Afficher la carte » ;
  - [ ] « Ouvrir dans Plans » ouvre Plans sur iPhone, ou Google Maps sur Android ;
  - [ ] « Ajouter à mon calendrier » :
    - iPhone : propose d'ajouter l'événement avec 3 alarmes ;
    - Android : télécharge le fichier .ics, qu'on ouvre avec Agenda ;
  - [ ] « Me rappeler » : le compte à rebours apparaît sur l'accueil si la course est dans 30 jours ou moins ;
  - [ ] « Préparer cette course » : la configuration du plan s'ouvre avec la course et la date déjà remplies, puis le plan se termine le jour de la course.
- [ ] Inscription d'un nouveau compte › étape objectif › « Choisir une course du calendrier ».
- [ ] Proposer une course depuis un compte non administrateur ; elle apparaît dans Gérer le calendrier › Propositions.
- [ ] Import : coller l'exemple de `docs/COURSES_SOURCES.md` › Aperçu › Importer.
- [ ] Supprimer les courses de test.

## Méthode et statistiques
- [ ] Profil › La méthode IKORUN : la page se lit bien dans les 3 langues.
- [ ] Plans exemples › 10 km › « Imprimer ou PDF » :

  - Android : Imprimer › Enregistrer au format PDF.
  - La page doit être blanche et lisible.
- [ ] Profil › Compte et données › Statistiques anonymes : l'interrupteur se coupe et se rallume.
- [ ] (Administrateur, après les migrations) Profil › Statistiques de l'app : les chiffres s'affichent.
