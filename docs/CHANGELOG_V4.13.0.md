# IKORUN 4.13.0 — Liberté dans l'onglet Sport
- Sport sans plan : trois choix de même poids (même style que l'inscription), plus de carte unique qui impose le plan IKORUN : « Plan IKORUN », « Mon plan » (plan personnel), « Juste courir ».
- « Juste courir » : une séance hors plan, saisie avec le bilan habituel (distance, durée, effort), sans la question « comme prévu ? ».
- La fin du tuto n'ouvre plus la création du plan d'office : elle mène à l'onglet Sport, où l'on choisit.
