# IKORUN v4.11.3 — « Complète ton profil » en assistant

Le bouton « Renseigner ma taille et mon poids » (Stats) ouvre maintenant le même assistant que l'inscription :
Ta taille (roue, cm) → Ton poids (roues kg + décimale, IMC en direct) → Ton cœur (FC repos / FC max, facultatif, FC max estimée d'après l'âge) → récapitulatif → construction.
Écrit P.height, P.weight, P.hrRest, P.hrMax comme « Modifier le profil ». Nouvelle fonction `bfFlowOpen()` (ui/plan-flow.js), 33 clés `bf2*` FR / EN / AR.

Versions : app 4.11.3, `app.min.js?v=163`, `app.min.css?v=71`, langues `v=18`, cache `ikorun-v149`.
