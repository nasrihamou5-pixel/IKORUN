# IKORUN v4.16.0 — style « Épuré »
- Profil › Apparence › Style : Classique (verre, reflets, relief) ou Épuré (surfaces plates, plus calme), dans toute l'app, en sombre et en clair.
- Épuré : cartes plates à bordure fine, sans reflet ni ombre ; boutons pleins de la couleur de l'app ; boutons secondaires en contour.
- Le style est appliqué dès l'ouverture (pas de flash).
