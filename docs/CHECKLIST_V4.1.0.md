# Checklist 4.1.0 (iPhone Safari, Android Chrome, Samsung Internet)

- [ ] Accueil : la rangée de pastilles s'affiche, toucher une pastille ouvre sa carte, le choix reste après redémarrage.
- [ ] Sport → Programme : sans plan, bouton « Créer un plan » ; avec un plan, semaine et points visibles.
- [ ] Nouveau plan → Les deux ensemble → Le générateur → Générer : message « Plan de muscu généré ».
- [ ] Sans plan de course : l'assistant demande d'abord le plan de course, puis reprend tout seul.
- [ ] Démarrer la séance de muscu du jour, la terminer : elle passe en « terminée ».
- [ ] Après une séance de jambes la veille d'un fractionné : la carte du coach annonce l'allègement, « Annuler » le retire.
- [ ] Badges : rang actuel, conditions du suivant, grille des 8 rangs ; toucher un rang ouvre son aperçu.
- [ ] Mêmes écrans en anglais et en arabe (de droite à gauche), en mode clair et sombre.
- [ ] Mode simple : l'onglet Programme n'apparaît pas.
