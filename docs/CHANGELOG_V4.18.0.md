# IKORUN 4.18.0
- L'app suit l'écran : sur tablette et ordinateur (≥ 700 px) elle n'est plus enfermée dans une colonne de 430 px. Elle occupe toute la fenêtre ; les cartes se répartissent en colonnes (Sport, Stats, Outils), l'Accueil passe sur deux colonnes, le Profil reste en une colonne de lecture centrée, les fenêtres et pages plein écran sont plus larges.
- Téléphones : inchangé, colonne pleine largeur, quelle que soit la taille de l'écran.
